# Kimia Farma Big Data Analytics

## Deskripsi Proyek
Proyek ini merupakan bagian dari tugas Big Data Analytics yang bertujuan untuk menganalisis data transaksi Kimia Farma menggunakan Google BigQuery dan Looker Studio.

## Tools yang Digunakan
- Google BigQuery untuk pengolahan dan analisis data menggunakan SQL.
- Looker Studio untuk visualisasi data dalam bentuk dashboard.
- GitHub untuk menyimpan dan mendokumentasikan kode SQL.

## Dataset
Proyek ini menggunakan empat dataset:
1. `kf_final_transaction`
2. `kf_inventory`
3. `kf_kantor_cabang`
4. `kf_product`

## Proses Analisis
1. Mengimpor dataset ke Google BigQuery.
2. Menggabungkan data transaksi, produk, dan kantor cabang.
3. Menghitung penjualan bersih (*nett sales*) dan keuntungan bersih (*nett profit*).
4. Membuat dashboard analisis performa bisnis menggunakan Looker Studio.

## Hasil Proyek
Hasil analisis disajikan dalam dashboard yang menampilkan indikator penjualan, tren pendapatan, performa cabang, rating, dan keuntungan.
